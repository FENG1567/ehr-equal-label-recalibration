# Third-party inputs and software

External Python libraries are dependencies, not vendored project code. Their licenses are not replaced by MIT. In particular NumPy, pandas, SciPy, scikit-learn, Matplotlib, PyArrow, Polars, statsmodels, PyTorch and python-docx retain their own licenses. See their installed distribution metadata and official repositories.
Historical MOTOR experiments refer to FEMR/MOTOR from Stanford; obtain the original package and model separately under its original conditions. This release does not contain the `third_party/femr0116` tree or pretrained MOTOR binaries. Historical MOTOR split summaries are the authors' aggregate results; they do not establish unseen-patient validation.
Database versions and links are documented in `docs/DATA_ACCESS.md`. No license in this repository replaces a database access agreement.
