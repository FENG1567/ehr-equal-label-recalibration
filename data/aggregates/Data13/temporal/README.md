# Temporal eligibility and endpoint qualification

MIMIC source metrics use the original MIMIC FM and conventional source prediction artifacts. External predictions are loaded through the recovered transport validator. Every cohort binds by database, stay, subject, sequence row, split, and label; mismatched prediction sets are not intersected. MIMIC source performance is limited to split 2; external metrics use the full eligible population. Frozen external partitions are not temporal validation.

H24 subsets include the included cohort, key exclusions, and flagged date-overlap, exit-gap, and administrative hospital-admit-after-H24 rows. The hospital-admit flag remains a descriptive flag; no-admin-after-H24 is a reported sensitivity subset. Per-model metrics include AUROC, Brier, log loss, and calibration point estimates. Paired FM versus LR Brier and log-loss differences use patient-cluster CIs with stay-weighted primary estimates and patient-weighted sensitivity estimates. The ICU bridge reports both weightings for paired loss differences; its 500-label calibration assessment uses one index episode per patient.

MIMIC calendar dates are de-identified and are not interpreted as true cross-patient calendar time. Only severity fields present in the cohort table are summarized; no unified score is inferred. Missing date-of-death intervals remain unknown. A verified y_mort=0 with finite current hospital exit after H24 resolves the date-boundary sensitivity without relabeling the date interval as known; a finite exact death timestamp also resolves the boundary, while proven early deaths remain excluded by the separate no-early-death sensitivity. Unknown boundary rows are counted in the flag audit. NWICU corrected mortality uses the documented known-alive and known-dead discharge-location whitelist; historical exact-string disagreements, corrected known-endpoint disagreements, and corrected labels versus frozen y_mort are reported separately with unknown values retained. The frozen NWICU eligibility gate is not changed; current-HADM death timing is restored from qualification_dod_v2_metadata.parquet using a one-to-one db/stay/subject join, with labels compared including permitted joint missingness, source path/hash, and full coverage evidence. Eligible selected rows require binary labels. SICdb frozen-label counts use neutral names and are not interpreted as verified hospital or ICU deaths. case_closure_relative_hr=(TimeOfStay-ICUOffset)/3600 is a case-close proxy, not an index-ICU exit; zero ICUOffset and case closing time do not verify continuous ICU occupancy at H24. SICdb performance rows are exploratory and explicitly tagged.
The process resource boundary is recorded from V5_RESOURCE_SCOPE, /proc/self/cgroup, and the enclosing cgroup memory.max, memory.high, memory.swap.max, and cpu.max values. The legacy user-1100.slice MemoryHigh is not assumed to enclose this process. The requested job cap remains 12 GiB, no swap, and 200% CPU; the observed values are in the manifests.
