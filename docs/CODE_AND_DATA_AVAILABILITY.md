# Code and data availability

**Code availability:** Analysis code, software requirements and aggregate results for reproducing the figures and tables are available at https://github.com/FENG1567/ehr-equal-label-recalibration/tree/v1.0.0. Author-developed code is licensed under the MIT License, and author-generated aggregate results are licensed under CC BY 4.0. Instructions for analyses requiring access to the original clinical databases are provided in `docs/CLINICAL_REPRODUCTION.md`.

The public workflow reproduces aggregate figures and table bodies from deposited aggregate inputs. Clinical refitting and patient-level reruns require separately authorized access to the original databases and the private inputs documented in the repository. The deposited reconstruction does not authenticate historical checkpoint membership or claim a full raw-data rerun.

**Data availability:** The six reused database versions and official access routes are listed in `docs/DATA_ACCESS.md`. Individual clinical records, patient-level derived predictions and training rosters are not redistributed. Public site-level aggregates omit low-support linked rows under the documented author-side release policy; complete clinical analyses require authorized access to the source records.
