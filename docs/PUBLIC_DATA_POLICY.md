# Public site-level data policy

For this open repository only, omit site-linked rows for any hospital with fewer than10 unique patients in either the historical hospital summary or repaired cohort roster. This is a conservative author-side release policy, not an asserted universal DUA threshold.

Original analyses, manuscript, complete private source and final submission files are unchanged. Suppression applies only to the separate open repository copy.

The public copy omits linked rows for 11 low-support sites. No individual site identifiers are listed in the suppression report. See provenance/public-site-suppression.json for affected file paths, counts and original/public hashes. Other source files remain identical to the final supplementary source. The fully populated research tables require the authorized original data workflow. This filtering does not change any of the eleven deposited figure specifications or seven publication table bodies.
