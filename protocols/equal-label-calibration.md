# Auditable pretraining and equal-label calibration sensitivity

This exploratory extension reuses the completed source-only three-seed numerical encoders and their source-selected frozen readouts. It does not certify historical checkpoint members. No new encoder is trained in this extension. New comparator or updating results have not been used to select the following design.

Compare each of the three numerical-real predictors with one conventional logistic regression using lossy summaries of the exact same quantized token arrays. For each of 48 variables use mean/min/max/standard deviation of bin values, retained-token count and mean retained hour. Absent variables have zero summary values; zero bin summary is distinct from observed bins1–10. This comparator does not receive continuous raw values. Fit scaling and coefficients on source split0; select C in .001/.01/.1/1/10/100 by source split1 Brier, breaking exact ties toward smaller C. Keep source split2 independent. The existing encoder readouts were selected by the same source-only criterion.

For each of eICU and NWICU, fix an outcome-independent patient split with seed20261124 into adaptation and assessment pools. A patient never occupies both roles. Select one outcome-independent stay per adaptation patient. Draw 500 or2000 natural patients without replacement in each of200 repetitions; all encoders and the conventional comparator receive exactly the same selected labels. A budget that lacks enough adaptation patients is explicitly infeasible. Fit Platt on adaptation labels only; single-class, constant-score, failed/nonconvergent or nonfinite fits use the predeclared Jeffreys prevalence fallback. Retain every attempt and report event support and fallback counts.

Assess all stays of independent assessment patients. Report raw and updated absolute Brier/log loss, paired encoder-minus-comparator differences and changes in those differences. Updated scores average per-stay losses over the200 fits, not losses of ensemble-averaged probabilities. Use500 shared assessment-patient cluster bootstrap draws for conditional stay-weighted intervals. Report all three seeds separately; seed extrema are descriptive ranges, not CIs. No equivalence claim is supported by an interval crossing zero without a clinical margin.

Source members, source-only bins, token arrays, training manifests, frozen readouts and reused predictions must be tied by hashes. Patient/stay/label alignment must be exact. Derived patient-level products stay on the server; only aggregates are delivered. This analysis remains based on retrospective measurement-time inputs in the existing source-only runs; it does not solve external bedside-availability or prospective-benefit evidence gaps. Its purpose is to test whether the equal-label calibration comparison can be reproduced without relying solely on the incompletely authenticated historical encoder.
